# Рубрика 10/10 — оценка интерфейса GOD (заполняет человек)

Ставь оценку 0–10 по каждому критерию, глядя на прод (vasiliad.github.io/GOD) и на
скриншоты в `output/qa_screens/`. Низкие оценки — это и есть дорожная карта: каждый
критерий с оценкой < 8 превращается в задачу.

| # | Критерий | На что смотреть | Оценка | Комментарий |
|---|---|---|---|---|
| 1 | Первый экран за 5 секунд | Понятно ли без слов, что это и что делать? (скрин 1) | | |
| 2 | Путь до первого ответа | Сколько секунд/кликов до «Бог ответил» в корпусном режиме? | | |
| 3 | Тон голоса Бога | «Просто говори» без канцелярита и без «спрашивай» — в заголовке, статусе, плейсхолдере | | |
| 4 | Честность маркировки | Всегда видно, что корпусный ответ — реальная речь эпизода, живой — рекомбинация имитации | | |
| 5 | Три языка | RU/EN/HE: переключение, полнота, иврит-RTL не ломает вёрстку (скрин 3) | | |
| 6 | Качество подбора эпизода | Пройди слепой лист bench_retrieval_sheet.md — вопрос про смысл | | |
| 7 | Мобильный вид | 390px: читаемость, тапы, не обрезано (скрин 4) | | |
| 8 | Отчёт | Читаемость научного текста в трёх языках, таблицы, RTL | | |
| 9 | Ошибки и отказы | Что видит посетитель при спящем мозге / медленном ответе — понятно ли, что делать | | |
| 10 | Целостность стиля | Тёмная тема, типографика, отступы, ничего «приклеенного» | | |

**Итог:** среднее по десяти = текущий X/10. Каждый < 8 — задача в бэклог с формулировкой
из колонки «Комментарий».

## Слепой лист retrieval (критерий 6)

`docs/bench_retrieval_sheet.md` — 22 вопроса × 3 анонимизированных варианта (А/Б/В).
Отметь лучший вариант в каждой строке, потом посмотри расшифровку в конце файла.
Итог: какой алгоритм победил по сумме — тот и включается на проде
(сейчас включён z-гибрид; лист может это подтвердить или опровергнуть — оба исхода
меняют код, это и есть независимая проверка).
