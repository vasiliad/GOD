# GOD — поведенческий профиль Бога в Танахе

**Исследование образа Бога в Танахе: все 39 книг, 2 050 эпизодов взаимодействия Человек↔Бог, извлечённых и размеченных по единому контракту.**

🌐 **Интерактивный браузер корпуса:** [vasiliad.github.io/GOD](https://vasiliad.github.io/GOD/)

## Что внутри

Каждый эпизод — размеченная сцена взаимодействия Человек↔Бог (17 полей):

- **спан стихов** (глава:стих — глава:стих) — прослеживается к тексту;
- **консонантная ивритская речь Бога** дословно (`god_speech_plain`) + огласовка;
- направление (`god_initiated` / `human_initiated` / `divine_action`), канал (direct / prophet / angel / dream / vision);
- **триггер** (что человек сделал: непослушание, мольба, заступничество, жалоба…) и **исход** (кара / завет / спасение / милость / молчание…);
- тяжесть 1–5, эмоции с цитатами-обоснованиями, русское резюме и описание действия.

## Ключевые находки

| Находка | Число |
|---|---|
| Наказание — 24% эпизодов; 57% кар — за непослушание; мольба наказывается в 0,4% | 494 эп. |
| Наказание «объявленное» (оракул) vs «исполненное» (действие) | 79% / 17% |
| Явная милость (прощение/отмена кары) — событийна, связана с заступничеством | 2,6% |
| Портрет по эпохам: Тора — завет (23%) · ранние Пророки — спасение · поздние Пророки — приговор (43%) · Кетувим — молчание (19%) | — |
| Инициатива: Бог 55% · человек 34% · действие без речи 10% | 2 050 эп. |

Полная аналитика: [`docs/data/analytics.json`](docs/data/analytics.json) · ретроспектива методологии: [`docs/retrospective_v1.md`](docs/retrospective_v1.md)

## Инструменты (`scripts/`)

| Скрипт | Что делает |
|---|---|
| `god_chat.py` | Имитация Бога: BM25-retrieval по корпусу → речь на библейском иврите + огласовка + подстрочник + английский + современный иврит + источники; вопросы на любых языках; диалоговая память (накопление проступков/благодати) |
| `god_behavior.py` | Движок поведения: классификация реплики → P(исход\|триггер) с модификаторами (покаяние, повторность) → прецеденты |
| `god_profile.py` | Поведенческий профиль корпуса: P(outcome\|trigger), тяжесть, эмоции |
| `analytics_v2.py` | Аналитика по книгам и эпохам (данные для веба) |
| `dedup_overlaps.py` | Глобальная дедупликация перекрытий эпизодов |
| `audit_god_names.py` | Аудит имён Бога в Танахе (26 форм; баг маккефа U+05BE) |
| `merge_audit_v2.py` | Аудит покрытия каждой книги (формулы речи/молчания/действия, контрольные стихи) |
| `run_v2_agents.py`, `pilot_v2_prepare.py` | Подготовка батчей и промптов экстракции |

Все скрипты имеют `--test`/`--selftest` режим; самопроверки PASS.

## Данные

- `output/episodes_TANAKH_v2.json` — мастер-корпус (2 050 эпизодов, без перекрытий)
- `output/god_behavior_profile.json` — P(исход|триггер) по корпусу
- `docs/data/books/*.json` — эпизоды по книгам (для веб-браузера)
- Танах: масоретский текст (общественное достояние, источник — Sefaria)

## Методология и честные ограничения

«Исходы» — кодировка исследователя (LLM-агенты с аудитами покрытия), а не теология;
молчание в поэтических книгах часто литературный приём. Выводы v1-этапа проекта
пересмотрены в [`docs/retrospective_v1.md`](docs/retrospective_v1.md) (правила
методологии закреплены в [SPEC.md](SPEC.md)). Слой DSS (Кумран) заблокирован
на источнике: открытых лицензированных транскрипций нет.
